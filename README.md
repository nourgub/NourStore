# NourStore

منصة الأستاذ متعددة الوكلاء — تنتج محتوى تربويًا كاملاً (امتحانات، حلول نموذجية، شبكات تنقيط) بصيغة Word جاهزة، بأسلوب ومنهج كل أستاذ.

## المرحلة الحالية

- **SaaS متعدد الأساتذة**: تسجيل/دخول حقيقي، وكل حساب معزول تمامًا عن غيره (وثائق، امتحانات، ملفات).
- **مادة الرياضيات فقط** كأول مادة كاملة التدفق (يمكن تكرار النمط لاحقًا على مواد أخرى).
- **فريق وكلاء الرياضيات** (`src/lib/agents/pipeline.ts`): محلّل المنهج ← واضع الأسئلة ← معدّ الحلول ← مصمم شبكة التنقيط ← المراجع.
- **التوليد بالذكاء الاصطناعي الحقيقي (Claude API) مفعَّل** عبر `src/lib/agents/realContent.ts` (نموذج `claude-sonnet-5`، مخرجات JSON مُقيَّدة بمخطط Zod). إذا لم يُضبط مفتاح `ANTHROPIC_API_KEY`، أو فشل النداء لأي سبب، تتراجع المنصة تلقائيًا إلى بنك أسئلة تجريبي (`src/lib/agents/mockContent.ts`) دون أي خطأ — ويظهر ذلك بوضوح في سجل عمل الوكلاء بصفحة النتائج.
- **التفعيل**: انسخ `.env.local.example` إلى `.env.local` وضع فيه مفتاحك من [console.anthropic.com](https://console.anthropic.com). الفوترة عند Anthropic حسب الاستخدام الفعلي فقط (لا اشتراك شهري ثابت)، وتكلفة توليد امتحان واحد كامل تقريبًا أقل من 0.05$.
- **ملفات Word حقيقية** (وليست مزيّفة) تُولَّد فعليًا عبر مكتبة `docx` لكل من الامتحان، الحل النموذجي، وشبكة التنقيط.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## البنية

```
src/
  app/                    صفحات ومسارات API (Next.js App Router)
  components/             مكوّنات الواجهة (نماذج تسجيل، رفع منهج، توليد امتحان)
  lib/
    db.ts                 تخزين JSON بسيط لكل من الأساتذة والوثائق والطلبات
    auth.ts / session.ts  تجزئة كلمات المرور وجلسات تسجيل الدخول
    agents/                خط أنابيب الوكلاء + بنك الأسئلة (mock)
    docx/                  توليد ملفات Word الثلاثة
```

## ما ينقص قبل الإنتاج الفعلي

- استخراج نص حقيقي من ملفات PDF/Word المرفوعة وتغذيته كسياق (RAG) للنموذج (حاليًا يُخزَّن اسم الملف فقط، والمحاور والمنهج تُدخَل يدويًا).
- قاعدة بيانات حقيقية بدل ملف JSON عند الانتقال لعدد أكبر من المستخدمين.
