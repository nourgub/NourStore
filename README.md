# NourStore

منصة الأستاذ متعددة الوكلاء — تنتج محتوى تربويًا كاملاً (امتحانات، حلول نموذجية، شبكات تنقيط) بصيغة Word جاهزة، بأسلوب ومنهج كل أستاذ.

## المرحلة الحالية

- **SaaS متعدد الأساتذة**: تسجيل/دخول حقيقي، وكل حساب معزول تمامًا عن غيره (وثائق، امتحانات، ملفات).
- **مادتان كاملتا التدفق: الرياضيات واللغة العربية** — خط الوكلاء (`src/lib/agents/pipeline.ts`) عامّ وغير مرتبط بمادة معينة؛ كل مادة تُسجَّل في `src/lib/agents/subjects.ts` (شخصية الوكيل + بنك الأسئلة + المحاور المتاحة)، فإضافة مادة جديدة لا تحتاج تعديل خط الأنابيب نفسه.
- **فريق الوكلاء** (عامّ لكل المواد): محلّل المنهج ← واضع الأسئلة ← معدّ الحلول ← مصمم شبكة التنقيط ← المراجع.
- **التوليد بالذكاء الاصطناعي الحقيقي (Claude API) مفعَّل** عبر `src/lib/agents/realContent.ts` (نموذج `claude-sonnet-5`، مخرجات JSON مُقيَّدة بمخطط Zod). إذا لم يُضبط مفتاح `ANTHROPIC_API_KEY`، أو فشل النداء لأي سبب، تتراجع المنصة تلقائيًا إلى بنك أسئلة تجريبي (`src/lib/agents/mockContent.ts`) دون أي خطأ — ويظهر ذلك بوضوح في سجل عمل الوكلاء بصفحة النتائج.
- **التفعيل**: انسخ `.env.local.example` إلى `.env.local` وضع فيه مفتاحك من [console.anthropic.com](https://console.anthropic.com). الفوترة عند Anthropic حسب الاستخدام الفعلي فقط (لا اشتراك شهري ثابت)، وتكلفة توليد امتحان واحد كامل تقريبًا أقل من 0.05$.
- **ملفات Word حقيقية** (وليست مزيّفة) تُولَّد فعليًا عبر مكتبة `docx` لكل من الامتحان، الحل النموذجي، وشبكة التنقيط.
- **استخراج حقيقي لمحتوى ملفات المنهج المرفوعة** (PDF عبر `pdf-parse`، Word .docx عبر `mammoth` — `src/lib/extractText.ts`) ويُغذَّى كسياق مرجعي في نداء Claude API مباشرة، وليس اسم الملف فقط.
- **قاعدة بيانات حقيقية (SQLite عبر `better-sqlite3`)** بدل ملف JSON — معاملات ذرية (transactions)، قيد UNIQUE فعلي على البريد الإلكتروني، مفاتيح خارجية (foreign keys)، بدل التحقق اليدوي من التكرار.
- **اشتراك/دفع يدوي عبر BaridiMob/CCP**: حساب جديد يبدأ بحالة "قيد الانتظار" ولا يمكنه توليد الامتحانات حتى يُفعَّل. صفحة `/billing` تعرض معلومات الدفع (سعر وهمي حاليًا، راجع أدناه) وتتيح رفع وصل الدفع (JPG/PNG/PDF) أو إرساله مباشرة عبر رابط واتساب. صفحة `/admin` (محمية ببريد `ADMIN_EMAIL`) تعرض الطلبات المعلّقة مع معاينة الوصل وزرّي تفعيل/رفض. حساب `ADMIN_EMAIL` نفسه يُفعَّل تلقائيًا دون حاجة للدفع.
  - **القيم الحالية وهمية بالكامل** (سعر، اسم صاحب الحساب، رقم BaridiMob/CCP، رقم واتساب) — اضبطها عبر `BILLING_PRICE_LABEL` / `BILLING_ACCOUNT_NAME` / `BILLING_ACCOUNT_RIP` / `BILLING_WHATSAPP_NUMBER` في `.env.local` قبل قبول أي دفع حقيقي.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## البنية

```
src/
  app/                    صفحات ومسارات API (Next.js App Router)
  components/             مكوّنات الواجهة (نماذج تسجيل، رفع منهج، توليد امتحان)
  lib/
    db.ts                 قاعدة بيانات SQLite (الأساتذة، الجلسات، الوثائق، الطلبات)
    auth.ts / session.ts  تجزئة كلمات المرور وجلسات تسجيل الدخول
    agents/                خط أنابيب عام + سجلّ المواد (subjects.ts) + بنك أسئلة mock لكل مادة
    docx/                  توليد ملفات Word الثلاثة
```

## ما ينقص قبل الإنتاج الفعلي

- **النشر على الإنترنت**: المنصة تعمل حاليًا محليًا فقط. قاعدة بيانات SQLite تعمل بشكل ممتاز على استضافة بقرص دائم (VPS عادي، أو حاويات Docker/Fly.io/Railway مع Volume) — لكنها **لا تعمل** على استضافة serverless ذات نظام ملفات مؤقت (مثل Vercel بإعداداته الافتراضية)؛ هناك يلزم إما قاعدة بيانات مُستضافة (Postgres عبر Supabase/Neon مثلاً) أو نشر على منصة بقرص دائم.
- استرجاع كلمة المرور وتأكيد البريد الإلكتروني.
- بوابة دفع إلكترونية فعلية (حاليًا تأكيد يدوي فقط عبر وصل BaridiMob/CCP — انظر أعلاه).
