# الفصل 6: الدوال الأساسية (**Fonctions**)

## 🎯 ماذا ستتعلم في هذا الفصل

- ما هي الدالة وكيف تُكتب.
- **Somme automatique** وأهم سبع دوال.
- معالج الدوال **Insérer une fonction**.

## 6-1 شكل الدالة

`=SOMME(B2:B10)`: اسم الدالة، ثم بين القوسين **الوسائط** (Arguments) مفصولة بـ **;**. مثال بعدة وسائط: `=SOMME(B2:B10;D2:D10;500)`.

## 6-2 الجمع التلقائي (**Somme automatique**)

انقر تحت عمود الأرقام ثم **Σ** في **Accueil** (أو **Alt+=**): يقترح Excel النطاق، فتضغط **Entrée**. السهم بجانب **Σ** يعطيك أيضاً **Moyenne**، **Nb**، **Max**، **Min**.

```shot
id: X11
title: قائمة Somme automatique
legend:
- زر Σ Somme automatique
- Somme، Moyenne، Nombres، Max، Min
- النطاق الذي اقترحه Excel بخط متقطع
- Autres fonctions… (كل الدوال)
```

## 6-3 الدوال السبع الأساسية

| الدالة | ماذا تفعل | مثال |
|---|---|---|
| `SOMME` | المجموع | `=SOMME(B2:B10)` |
| `MOYENNE` | المعدل | `=MOYENNE(B2:B10)` |
| `MAX` / `MIN` | الأكبر / الأصغر | `=MAX(B2:B10)` |
| `NB` | عدد الخلايا التي فيها **أرقام** | `=NB(B2:B10)` |
| `NBVAL` | عدد الخلايا **غير الفارغة** | `=NBVAL(A2:A10)` |
| `ARRONDI` | التقريب | `=ARRONDI(B2;2)` |
| `AUJOURDHUI` | تاريخ اليوم | `=AUJOURDHUI()` |

## 6-4 معالج الدوال

لا تتذكر وسائط دالة؟ انقر على **fx** بجانب **Barre de formule**:

```shot
id: X12
title: نافذة Insérer une fonction
legend:
- خانة البحث عن دالة بالوصف
- Catégorie: Les dernières utilisées، Logique، Recherche et référence…
- قائمة الدوال
- شرح الدالة المختارة ووسائطها
```

ثم تظهر نافذة **Arguments de la fonction**: لكل وسيط خانة، وتحتها النتيجة مباشرة قبل أن تضغط **OK**.

> 💡 **نصيحة:** أثناء كتابة `=SOM` يقترح Excel قائمة الدوال. اضغط **Tab** لاختيار الدالة المظللة.

## 📝 الخلاصة

- الدالة = اسم + وسائط بين قوسين مفصولة بـ **;**.
- **Alt+=** للجمع التلقائي.
- `NB` للأرقام، `NBVAL` لكل الخلايا غير الفارغة.
- **fx** يفتح المعالج.

## 🛠️ تمرين

في ورقة **Ch6-7 Fonctions** من ملف التمارين، أجب عن الأسئلة الثلاثة الأولى بـ `SOMME` و`MOYENNE` و`MAX`.
