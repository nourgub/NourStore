# الجزء الأول: البداية

# الفصل 1: اكتشف واجهة Excel (**Interface**)

## 🎯 ماذا ستتعلم في هذا الفصل

- الفرق بين المصنف والورقة والخلية.
- أجزاء نافذة Excel.
- التنقل بين الخلايا والأوراق.

## 1-1 المصنف والورقة والخلية

- **Classeur** (المصنف): الملف كله، امتداده **.xlsx**.
- **Feuille** (الورقة): صفحة داخل المصنف. المصنف الواحد قد يحتوي عشرات الأوراق (مثلاً ورقة لكل شهر).
- **Cellule** (الخلية): المربع الصغير الذي تكتب فيه. اسمها حرف عمودها ثم رقم سطرها: **B3** هي العمود B والسطر 3.
- **Plage** (النطاق): مجموعة خلايا متجاورة، تُكتب `A1:D10` أي من A1 إلى D10.

## 1-2 أجزاء النافذة

افتح Excel، ثم **Nouveau classeur vierge** (مصنف فارغ):

```shot
id: X01
title: نافذة Excel وأجزاؤها
legend:
- الشريط (Ruban) وتبويباته: Accueil، Insertion، Formules، Données…
- Zone Nom: اسم الخلية النشطة (هنا C3)
- Barre de formule: محتوى الخلية أو صيغتها
- رؤوس الأعمدة (A، B، C…) ورؤوس الأسطر (1، 2، 3…)
- الخلية النشطة بإطار أخضر، ومقبض التعبئة في زاويتها
- تبويبات الأوراق (Feuil1) وزر + لإضافة ورقة
- شريط الحالة: Moyenne، Nb، Somme للخلايا المحددة
```

> 💡 **نصيحة:** حدّد عدة خلايا فيها أرقام وانظر إلى **شريط الحالة** في الأسفل: Excel يعطيك المجموع والمعدل فوراً بلا أي صيغة.

## 1-3 التنقل السريع

| تريد | اضغط |
|---|---|
| الخلية التالية تحت | **Entrée** |
| الخلية التالية يميناً | **Tab** |
| آخر خلية مملوءة في الاتجاه | **Ctrl+السهم** |
| الخلية A1 | **Ctrl+Origine** |
| الورقة التالية / السابقة | **Ctrl+Pg.Suiv** / **Ctrl+Pg.Préc** |
| الذهاب إلى خلية معينة | اكتب اسمها في **Zone Nom** ثم **Entrée** |

## 1-4 الأوراق

- **إضافة**: زر **+** بجانب تبويبات الأوراق.
- **إعادة التسمية**: نقر مزدوج على التبويب، ثم اكتب الاسم (مثلاً «Janvier»).
- **النقل أو النسخ**: اسحب التبويب، أو زر أيمن ثم **Déplacer ou copier**.
- **اللون**: زر أيمن ثم **Couleur d'onglet**.

> ⚠️ **تحذير:** حذف ورقة (**Supprimer**) لا يُلغى بـ **Ctrl+Z**. تأكد قبل الحذف.

## 📝 الخلاصة

- المصنف ← أوراق ← خلايا، والخلية اسمها عمود + سطر (B3).
- **Zone Nom** و**Barre de formule** أهم جزأين بعد الشبكة.
- شريط الحالة يعطيك مجموعاً سريعاً بلا صيغة.

أنشئ مصنفاً فيه ثلاث أوراق: «Janvier» و«Février» و«Mars»، لوّن كل تبويب بلون، واحفظه باسم «Mes-mois.xlsx».
