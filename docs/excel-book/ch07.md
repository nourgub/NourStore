# الفصل 7: الشروط (**SI**, **NB.SI**, **SOMME.SI**)

## 🎯 ماذا ستتعلم في هذا الفصل

- الدالة `SI` لاتخاذ قرار.
- الشروط المتعددة: `ET`، `OU`، و`SI` المتداخلة.
- العدّ والجمع بشرط: `NB.SI` و`SOMME.SI` و`SOMME.SI.ENS`.
- `SIERREUR` لإخفاء الأخطاء.

## 7-1 الدالة SI

`=SI(test;valeur_si_vrai;valeur_si_faux)`

مثال: «Admis» إن كان المعدل 10 أو أكثر، وإلا «Ajourné»:

`=SI(H7>=10;"Admis";"Ajourné")`

**عوامل المقارنة:** `=` يساوي، `<>` لا يساوي، `>` أكبر، `<` أصغر، `>=` أكبر أو يساوي، `<=` أصغر أو يساوي.

## 7-2 عدة شروط

- `ET`: كل الشروط صحيحة. `=SI(ET(B2>=10;C2>=10);"Validé";"Non")`
- `OU`: شرط واحد يكفي. `=SI(OU(D2="Rupture";D2="À commander");"Commander";"")`
- **SI متداخلة** للتقديرات:

`=SI(H7>=16;"Très bien";SI(H7>=14;"Bien";SI(H7>=12;"Assez bien";SI(H7>=10;"Passable";""))))`

> 💡 **نصيحة:** في Microsoft 365 وExcel 2019 وما بعده، `SI.CONDITIONS` أوضح: `=SI.CONDITIONS(H7>=16;"Très bien";H7>=14;"Bien";H7>=12;"Assez bien";H7>=10;"Passable";VRAI;"")`

## 7-3 العدّ والجمع بشرط

| الدالة | السؤال | مثال |
|---|---|---|
| `NB.SI` | كم خلية تحقق الشرط؟ | `=NB.SI(K7:K22;"Admis")` |
| `SOMME.SI` | ما مجموع القيم التي تحقق الشرط؟ | `=SOMME.SI(B5:B10;"Marketing";C5:C10)` |
| `SOMME.SI.ENS` | المجموع بعدة شروط | `=SOMME.SI.ENS(G:G;B:B;"Nord";H:H;3)` |
| `NB.SI.ENS` | العدّ بعدة شروط | `=NB.SI.ENS(B:B;"Nord";E:E;">5")` |
| `MOYENNE.SI` | المعدل بشرط | `=MOYENNE.SI(B:B;"Sud";G:G)` |

## 7-4 SIERREUR

بدل أن يظهر **#DIV/0!** أو **#N/A**: `=SIERREUR(B2/C2;0)` أو `=SIERREUR(RECHERCHEV(…);"Introuvable")`.

## 📝 الخلاصة

- `SI(test;vrai;faux)` للقرار، و`ET`/`OU` لعدة شروط.
- `NB.SI` تعدّ، `SOMME.SI` تجمع، و`.ENS` لعدة شروط.
- `SIERREUR` يجعل الجداول نظيفة.
