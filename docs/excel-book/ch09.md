# الفصل 9: النصوص والتواريخ

## 🎯 ماذا ستتعلم في هذا الفصل

- تنظيف النصوص وتقسيمها ودمجها.
- الحساب بالتواريخ: العمر، الأيام، أيام العمل.
- `TEXTE` لعرض الأرقام والتواريخ بالشكل الذي تريد.

## 9-1 دوال النص

| الدالة | ماذا تفعل | مثال ← النتيجة |
|---|---|---|
| `SUPPRESPACE` | يحذف المسافات الزائدة | `=SUPPRESPACE("  sami   EXEMPLE ")` ← sami EXEMPLE |
| `NOMPROPRE` | أول حرف كبير | `=NOMPROPRE("sami EXEMPLE")` ← Sami Exemple |
| `MAJUSCULE` / `MINUSCULE` | كله كبير / صغير | `=MAJUSCULE("p004")` ← P004 |
| `GAUCHE` / `DROITE` | أول / آخر n حروف | `=GAUCHE("P004-ALG";4)` ← P004 |
| `STXT` | حروف من الوسط | `=STXT("F-2026-0042";3;4)` ← 2026 |
| `NBCAR` | عدد الحروف | `=NBCAR("Excel")` ← 5 |
| `CONCAT` أو `&` | دمج | `=A2&" "&B2` |
| `TROUVE` | موقع حرف | `=TROUVE(" ";A2)` |

## 9-2 التواريخ

التاريخ في Excel **عدد**: عدد الأيام منذ 1 يناير 1900. لهذا تستطيع طرح تاريخين: `=C2-B2` = عدد الأيام بينهما.

| الدالة | ماذا تفعل |
|---|---|
| `AUJOURDHUI()` | تاريخ اليوم (يتحدث كل يوم) |
| `ANNEE(A2)` / `MOIS(A2)` / `JOUR(A2)` | السنة / الشهر / اليوم من تاريخ |
| `DATE(2026;10;5)` | يبني تاريخاً من ثلاثة أرقام |
| `DATEDIF(A2;AUJOURDHUI();"y")` | العمر بالسنوات ("m" للأشهر، "d" للأيام) |
| `NB.JOURS.OUVRES(début;fin)` | أيام العمل بين تاريخين |
| `NB.JOURS.OUVRES.INTL(début;fin;7)` | نفس الشيء مع عطلة الجمعة والسبت |
| `FIN.MOIS(A2;0)` | آخر يوم في الشهر |

> 💡 **نصيحة:** `DATEDIF` دالة «مخفية»: لا يقترحها Excel أثناء الكتابة ولا تظهر في المعالج، لكنها تعمل. اكتبها كاملة.

> 💡 **نصيحة:** في بلدان عطلتها الجمعة والسبت، الرقم **7** في `NB.JOURS.OUVRES.INTL` يعني «الجمعة والسبت».

## 9-3 الدالة TEXTE

تحوّل عدداً أو تاريخاً إلى نص بالشكل الذي تختاره:

- `=TEXTE(A2;"jjjj")` ← اسم اليوم (lundi).
- `=TEXTE(A2;"mmmm aaaa")` ← octobre 2026.
- `="Total : "&TEXTE(E25;"# ##0,00")&" DA"`.

## 📝 الخلاصة

- `SUPPRESPACE` و`NOMPROPRE` لتنظيف البيانات المنسوخة.
- `GAUCHE` و`STXT` و`DROITE` لتقطيع النص، و`&` للدمج.
- التاريخ عدد: اطرح، واستعمل `DATEDIF` للعمر.
