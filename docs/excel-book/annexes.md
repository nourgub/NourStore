# الملحق أ: اختصارات لوحة المفاتيح (**Raccourcis clavier**)

ابدأ بالجدول الأول، وأضف كل أسبوع خمسة اختصارات جديدة. الاختصارات المعلَّمة بـ * يجب تجربتها على لوحة مفاتيحك (AZERTY أو QWERTY) لأنها تعتمد على مكان الرموز.

> 💡 **أهم قاعدة:** مرّر الفأرة فوق أي زر في الشريط: يظهر اسمه واختصاره في نسختك.

> ⚠️ **ملاحظة:** الاختصارات أدناه هي الرسمية في Excel لـ Windows (Microsoft 365). بعض الاختصارات التي فيها رموز (مثل **Ctrl+;** أو **Ctrl+Maj+$**) قد تختلف حسب لوحة المفاتيح (AZERTY أو QWERTY). جرّب، أو استعمل الزر المقابل في الشريط.

**المفاتيح بالفرنسية:** **Maj** = Shift، **Entrée** = Enter، **Suppr** = Delete، **Origine** = Home، **Fin** = End، **Échap** = Esc، **Pg.Suiv / Pg.Préc** = Page Down / Page Up.

## أ-7 الشريط بلوحة المفاتيح

اضغط **Alt** وحده فتظهر حروف على التبويبات والأزرار، ثم اضغط الحرف. الحروف تختلف حسب لغة النسخة، فاتبع ما يظهر على شاشتك. **Ctrl+F1** يُخفي الشريط أو يُظهره، و**Alt+Q** يفتح خانة البحث **Rechercher**.

> 📌 **المصدر:** صفحة الدعم الرسمية «Raccourcis clavier dans Excel» على support.microsoft.com (Windows، Microsoft 365). في Mac تستعمل **Cmd** غالباً بدل **Ctrl**.

# الملحق ج: رسائل الأخطاء وحلولها

| الخطأ | المعنى | الحل |
|---|---|---|
| **#####** | العمود ضيق جداً | وسّع العمود (نقر مزدوج على حده) |
| **#DIV/0!** | قسمة على صفر أو خلية فارغة | `=SI(C2=0;0;B2/C2)` أو `SIERREUR` |
| **#N/A** | القيمة غير موجودة في البحث | تحقق من الرمز والمسافات، و`FAUX` في `RECHERCHEV` |
| **#NOM?** | اسم دالة خاطئ أو نص بلا تنصيص | صحّح الاسم (`SOMME` لا `SUM` في النسخة الفرنسية) |
| **#VALEUR!** | عملية على نص بدل عدد | تحقق أن الخلايا أرقام لا نصوص |
| **#REF!** | المرجع محذوف | تراجع بـ Ctrl+Z أو أعد كتابة الصيغة |
| **#NOMBRE!** | عدد غير ممكن (جذر سالب…) | راجع القيم المدخلة |
| **#PROPAGATION!** | نتيجة مصفوفة لا تجد مكاناً فارغاً | أفرغ الخلايا تحت الصيغة (Microsoft 365) |
| **مرجع دائري** | الصيغة تشير إلى نفسها | **Formules** ثم **Vérification des erreurs** ثم **Références circulaires** |

```shot
id: X32
title: الأخطاء الشائعة كما تظهر في الورقة
legend:
- المثلث الأخضر في زاوية الخلية: تحذير
- زر التحذير وخياراته (Ignorer l'erreur، Aide…)
- #DIV/0! و#N/A و#NOM? في الخلايا
- Formules ثم Vérification des erreurs
```

> 💡 **نصيحة:** **Formules** ثم **Afficher les formules** (**Ctrl+`**) يعرض كل الصيغ مكان النتائج: أفضل طريقة لفهم ملف لم تصنعه أنت.
