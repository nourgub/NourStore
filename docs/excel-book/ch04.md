# الفصل 4: الأوراق الكبيرة والطباعة

## 🎯 ماذا ستتعلم في هذا الفصل

- إدراج وحذف الأسطر والأعمدة، وإخفاؤها.
- تجميد العناوين أثناء التمرير.
- طباعة جدول كبير في صفحة واحدة.

## 4-1 الأسطر والأعمدة

| تريد | الطريقة |
|---|---|
| إدراج سطر | زر أيمن على رقم السطر ثم **Insérer** (أو **Ctrl++**) |
| حذف عمود | زر أيمن على حرف العمود ثم **Supprimer** (أو **Ctrl+-**) |
| إخفاء عمود | زر أيمن ثم **Masquer** |
| إظهاره | حدّد العمودين حوله، زر أيمن ثم **Afficher** |
| عرض تلقائي | نقر مزدوج على الحد بين رأسي العمودين |

## 4-2 تجميد الأجزاء (**Figer les volets**)

في جدول من 500 سطر، تختفي العناوين عند النزول. الحل:

1. انقر على الخلية التي **تحت** سطر العناوين و**يمين** العمود الذي تريد تثبيته (مثلاً **B2**).
2. **Affichage** ثم **Figer les volets** ثم **Figer les volets**.

```shot
id: X07
title: قائمة Figer les volets
legend:
- تبويب Affichage
- زر Figer les volets
- Figer les volets (حسب الخلية المحددة)
- Figer la ligne supérieure / la première colonne
- الخط الرمادي الذي يفصل الجزء المجمد
```

## 4-3 الطباعة

**Fichier** ثم **Imprimer** (**Ctrl+P**). أهم الإعدادات:

- **Orientation paysage** للجداول العريضة.
- **Ajuster la feuille à une page**، أو **Ajuster toutes les colonnes à une page** (الأفضل للجداول الطويلة).
- **Zone d'impression**: حدّد الجزء الذي تريده فقط، ثم **Mise en page** ثم **Zone d'impression** ثم **Définir**.
- **Imprimer les titres**: يكرر سطر العناوين في أعلى كل صفحة (**Mise en page** ثم **Imprimer les titres** ثم **Lignes à répéter en haut**).

```shot
id: X08
title: شاشة الطباعة في Excel
legend:
- زر Imprimer وعدد النسخ
- Imprimer les feuilles actives / la sélection
- Orientation paysage
- Mise à l'échelle: Ajuster toutes les colonnes à une page
- معاينة الصفحة
```

> 💡 **نصيحة:** **Affichage** ثم **Aperçu des sauts de page** يُظهر حدود كل صفحة بخط أزرق تستطيع سحبه.

## 📝 الخلاصة

- **Ctrl++** و**Ctrl+-** للإدراج والحذف.
- **Figer les volets** يُبقي العناوين ظاهرة.
- **Ajuster toutes les colonnes à une page** + **Imprimer les titres** لطباعة نظيفة.
