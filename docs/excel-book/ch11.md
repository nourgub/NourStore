# الفصل 11: الرسوم البيانية (**Graphiques**)

## 🎯 ماذا ستتعلم في هذا الفصل

- اختيار الرسم المناسب لبياناتك.
- إنشاء رسم وتعديل عناصره.
- الرسوم الصغيرة داخل الخلايا (**Sparklines**).

## 11-1 أي رسم أختار؟

| تريد أن تُظهر | الرسم | بالفرنسية |
|---|---|---|
| مقارنة فئات (مبيعات كل بائع) | أعمدة أو أشرطة | **Histogramme** / **Barres** |
| تطور عبر الزمن (المبيعات شهرياً) | خطوط | **Courbes** |
| أجزاء من كل (حصة كل منتج) | دائري (5 أجزاء كحد أقصى) | **Secteurs** |
| المتوقع مقابل الفعلي | أعمدة مجمّعة | **Histogramme groupé** |

## 11-2 إنشاء رسم

1. حدّد البيانات مع عناوينها (مثلاً الأشهر والمبالغ).
2. **Insertion** ثم **Graphiques recommandés**.
3. اختر الشكل ثم **OK**.

```shot
id: X21
title: نافذة Graphiques recommandés
legend:
- تبويب Graphiques recommandés
- الأشكال المقترحة حسب بياناتك
- المعاينة الكبيرة
- Tous les graphiques (كل الأنواع)
```

> 💡 **نصيحة:** أسرع طريقة: حدّد البيانات واضغط **Alt+F1** لرسم داخل الورقة، أو **F11** لرسم في ورقة مستقلة.

## 11-3 تعديل الرسم

انقر على الرسم: تظهر ثلاثة أزرار بجانبه وتبويبان **Création de graphique** و**Format**:

```shot
id: X22
title: أزرار الرسم البياني
legend:
- زر + Éléments de graphique: العنوان، التسميات، وسيلة الإيضاح
- زر الفرشاة Styles du graphique: الأسلوب والألوان
- زر القمع Filtres du graphique: إخفاء سلسلة أو فئة
- العنوان: انقر عليه لتكتب عنواناً واضحاً
- تبويب Création de graphique: Modifier le type، Sélectionner des données
```

- **Étiquettes de données** تكتب الرقم فوق كل عمود: مفيدة جداً في التقارير.
- **Sélectionner des données** لإضافة سلسلة أو تغيير النطاق.
- **Déplacer le graphique** لنقله إلى ورقة مستقلة.

## 11-4 الرسوم داخل الخلايا (**Sparklines**)

**Insertion** ثم **Courbes** في مجموعة **Graphiques sparkline**: رسم صغير جداً داخل خلية واحدة، يُظهر اتجاه كل سطر (مثلاً مبيعات كل بائع عبر الأشهر).

## 📝 الخلاصة

- الأعمدة للمقارنة، والخطوط للزمن، والدائري للحصص (قليلة).
- **Graphiques recommandés** أو **Alt+F1**.
- أزرار + والفرشاة والقمع بجانب الرسم.

## 🛠️ تمرين

من ورقة **Ch10-12 Données**: اصنع رسماً بالأعمدة لمجموع المبالغ حسب المدينة (احسبها أولاً بـ `SOMME.SI`)، أضف عنواناً و**Étiquettes de données**.
