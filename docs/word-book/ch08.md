# الجزء الثالث: الإثراء

# الفصل 8: الجداول (**Tableaux**)

## 🎯 ماذا ستتعلم في هذا الفصل

- إدراج جدول وكتابة البيانات فيه.
- إضافة وحذف الأسطر والأعمدة، ودمج الخلايا.
- تصميم الجدول بأنماط جاهزة.
- ترتيب البيانات ومجموع بسيط.

## 8-1 إدراج جدول

1. **Insertion** ثم **Tableau**.
2. مرّر الفأرة على الشبكة لتختار عدد الأعمدة والأسطر (مثلاً 4×5)، ثم انقر.
3. للتنقل بين الخلايا: **Tab** للخلية التالية، **Maj+Tab** للسابقة. **Tab** في آخر خلية يضيف سطراً جديداً.

```shot
id: W23
title: قائمة Tableau
take: Insertion ثم Tableau، مرّر الفأرة على شبكة 4×5 بدون نقر، وصوّر القائمة
legend:
- زر Tableau
- الشبكة لاختيار الحجم
- Insérer un tableau… (بعدد دقيق)
- Dessiner un tableau
```

## 8-2 تبويبا الجدول

عند النقر داخل الجدول يظهر تبويبان جديدان:

- **Création de tableau**: الألوان والأنماط والحدود.
- **Disposition**: الأسطر والأعمدة والدمج والمحاذاة.

```shot
id: W24
title: تبويب Création de tableau
take: انقر داخل جدول فيه بيانات، افتح Création de tableau، وصوّر النافذة
legend:
- Options de style: Ligne d'en-tête، Lignes à bandes
- معرض أنماط الجداول
- Trame de fond (تظليل الخلايا)
- Bordures
```

```shot
id: W25
title: تبويب Disposition
take: انقر داخل الجدول، افتح Disposition، وصوّر النافذة
legend:
- Insérer au-dessus / en dessous / à gauche / à droite
- Supprimer
- Fusionner les cellules / Fractionner
- محاذاة النص داخل الخلية
- Trier وFormule
```

## 8-3 تعديل البنية

| تريد | الطريقة |
|---|---|
| سطر جديد | **Disposition** ثم **Insérer en dessous** |
| حذف عمود | **Disposition** ثم **Supprimer** ثم **Supprimer les colonnes** |
| دمج خلايا | حدّدها ثم **Fusionner les cellules** |
| تكرار سطر العنوان في كل صفحة | **Disposition** ثم **Répéter les lignes d'en-tête** |
| جدول من اليمين إلى اليسار | **Propriétés** ثم اتجاه الجدول **De droite à gauche** |

## 8-4 الترتيب والمجموع

- **Trier**: رتّب الأسطر حسب عمود (أبجدياً أو رقمياً).
- **Formule**: في الخلية الأخيرة اكتب **=SUM(ABOVE)** لمجموع الأرقام فوقها.

> ⚠️ **تحذير:** Word ليس Excel: المجموع لا يتحدث تلقائياً. بعد تغيير الأرقام، انقر على النتيجة واضغط **F9**. للحسابات الكثيرة استعمل Excel.

## 📝 الخلاصة

- **Insertion** ثم **Tableau** للإدراج، و**Tab** للتنقل.
- **Création de tableau** للشكل، **Disposition** للبنية.
- **Répéter les lignes d'en-tête** للجداول الطويلة.

## 🛠️ تمرين

أنشئ جدول أسعار لمحل: المنتج، الكمية، السعر، المجموع. لوّن سطر العنوان، وأضف سطر «المجموع الكلي» بدمج خليتين.
