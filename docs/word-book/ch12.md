# الفصل 12: التدقيق والعمل الجماعي (**Révision**)

## 🎯 ماذا ستتعلم في هذا الفصل

- التدقيق الإملائي والنحوي بـ **Éditeur**.
- إضافة التعليقات والرد عليها.
- تتبّع التعديلات وقبولها أو رفضها.
- مقارنة نسختين ومشاركة المستند.

## 12-1 التدقيق (**Éditeur**)

- خط أحمر متموّج تحت الكلمة = خطأ إملائي. خط أزرق مزدوج = خطأ نحوي أو أسلوبي.
- زر أيمن على الكلمة لرؤية الاقتراحات.
- **Accueil** ثم **Éditeur** (أو **F7**) لمراجعة المستند كله.

```shot
id: W38
title: جزء Éditeur
take: اكتب جملة فرنسية فيها خطأين متعمدين، اضغط F7، وصوّر النافذة مع جزء Éditeur
legend:
- النتيجة العامة للمستند
- Corrections: Orthographe، Grammaire
- Améliorations: Clarté، Concision
- الخطأ مُبرز في النص
```

**لغة التدقيق**: إن ظهرت كل الكلمات العربية بخط أحمر، حدّد النص ثم **Révision** ثم **Langue** ثم **Définir la langue de vérification** ثم **Arabe (Algérie)** أو بلدك.

> ⚠️ **تحذير:** التدقيق الآلي يساعد ولا يُغني: لا يكتشف «أن» مكان «إن» في كل الحالات. اقرأ بنفسك قبل التسليم.

## 12-2 التعليقات (**Commentaires**)

1. حدّد الكلمة أو الجملة.
2. **Révision** ثم **Nouveau commentaire** (**Ctrl+Alt+M**).
3. اكتب ملاحظتك ثم زر الإرسال.

يستطيع غيرك **الرد** على التعليق أو **حلّه** (**Résoudre**) عندما يُعالج.

```shot
id: W39
title: تعليق في الهامش
take: حدّد جملة، أضف تعليقاً «أعد صياغة هذه الجملة»، وصوّر النافذة
legend:
- Nouveau commentaire
- النص المعلَّق عليه
- التعليق في الهامش
- Répondre / Résoudre
```

## 12-3 تتبّع التعديلات (**Suivi des modifications**)

مثالي عندما يراجع أستاذك أو زميلك عملك:

1. **Révision** ثم **Suivi des modifications** (**Ctrl+Maj+E**): يصبح الزر ملوناً.
2. كل حذف يظهر مشطوباً، وكل إضافة ملونة ومسطرة.
3. لإنهاء المراجعة: **Accepter** أو **Refuser** لكل تعديل، أو **Accepter toutes les modifications**.

```shot
id: W40
title: تعديلات متتبَّعة
take: فعّل Suivi des modifications، احذف كلمة وأضف أخرى، وصوّر النافذة مع تبويب Révision
legend:
- زر Suivi des modifications مفعّل
- كلمة محذوفة (مشطوبة)
- كلمة مضافة (ملونة)
- Accepter / Refuser
- Précédent / Suivant
```

> 💡 **نصيحة:** قائمة **Marques simples / Toutes les marques / Aucune marque** تغيّر العرض فقط. التعديلات لا تُقبل إلا بـ **Accepter**.

## 12-4 المقارنة والمشاركة

- **Comparer**: **Révision** ثم **Comparer** ثم اختر النسخة الأصلية والمعدّلة: ينتج Word مستنداً يظهر الفروق كتعديلات متتبَّعة.
- **Partager**: الزر أعلى يمين النافذة. احفظ المستند في **OneDrive** أولاً، ثم أرسل رابطاً بصلاحية **Modifier** أو **Afficher** فقط.
- **Co-édition**: عدة أشخاص في نفس المستند في الوقت نفسه، وترى مؤشر كل واحد باسمه.

```shot
id: W41
title: نافذة Partager
take: انقر على Partager في مستند محفوظ على OneDrive، وصوّر النافذة دون إظهار أي بريد حقيقي
legend:
- خانة إضافة الأشخاص
- صلاحية Modifier / Afficher
- Copier le lien
```

> ⚠️ **تحذير:** عند تصوير هذه النافذة لا تُظهر عناوين بريد أو أسماء أشخاص حقيقيين.

## 📝 الخلاصة

- **F7** للتدقيق، وغيّر لغة التدقيق للنص العربي.
- **Ctrl+Alt+M** تعليق، **Ctrl+Maj+E** تتبّع التعديلات.
- **Comparer** يكشف الفروق بين نسختين.
- **Partager** يحتاج المستند على OneDrive.

## 🛠️ تمرين

فعّل تتبّع التعديلات، صحّح 3 أخطاء في فقرة، وأضف تعليقاً واحداً. ثم اقبل تعديلين وارفض الثالث، واحلل التعليق.
