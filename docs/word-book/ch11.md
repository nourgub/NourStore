# الجزء الرابع: الاحتراف

# الفصل 11: المذكرات والبحوث (**Références**)

## 🎯 ماذا ستتعلم في هذا الفصل

- إنشاء جدول محتويات تلقائي وتحديثه.
- إضافة حواشٍ أسفل الصفحة.
- قائمة الأشكال من تعليقات الصور.
- إدارة المراجع وقائمة البيبليوغرافيا.

## 11-1 جدول المحتويات (**Table des matières**)

الشرط الوحيد: أن تكون عناوينك بأنماط **Titre 1/2/3** (الفصل 6).

1. ضع المؤشر في صفحة فارغة بعد الغلاف.
2. **Références** ثم **Table des matières** ثم **Table automatique 1**.
3. بعد أي تعديل في المستند: انقر داخل الجدول ثم **Mettre à jour la table** ثم **Mettre à jour toute la table**.

```shot
id: W32
title: قائمة Table des matières
take: في مستند فيه عناوين Titre 1 وTitre 2، افتح Références ثم Table des matières، وصوّر القائمة مفتوحة
legend:
- تبويب Références
- Table automatique 1 / 2
- Table des matières personnalisée…
- Supprimer la table des matières
```

```shot
id: W33
title: جدول محتويات بعد الإدراج
take: أدرج الجدول، ثم انقر داخله حتى يظهر زر Mettre à jour la table، وصوّر الصفحة
legend:
- زر Mettre à jour la table
- العناوين بمستوياتها
- أرقام الصفحات
```

> 💡 **نصيحة:** **Ctrl+نقرة** على سطر في الجدول تنقلك مباشرة إلى ذلك العنوان.

> ⚠️ **تحذير:** لا تكتب أرقام الصفحات في الجدول بيدك: كل تعديل يُفسدها. حدّث الجدول قبل الطباعة دائماً (أو اضغط **F9** داخله).

## 11-2 الحواشي (**Notes de bas de page**)

1. ضع المؤشر بعد الكلمة أو الاقتباس.
2. **Références** ثم **Insérer une note de bas de page** (**Ctrl+Alt+F**).
3. يضع Word رقماً صغيراً وينقلك أسفل الصفحة لتكتب المصدر.

```shot
id: W34
title: حاشية أسفل الصفحة
take: اكتب فقرة، أدرج حاشية بعد كلمة واكتب فيها مصدراً، وصوّر النافذة مع ظهور الرقم والحاشية
legend:
- Insérer une note de bas de page
- الرقم داخل النص
- الحاشية أسفل الصفحة
- Insérer une note de fin
```

**Note de fin** (**Ctrl+Alt+D**) مثل الحاشية، لكنها تجتمع في آخر المستند.

## 11-3 قائمة الأشكال (**Table des illustrations**)

إذا أضفت تعليقات للصور بـ **Insérer une légende** (الفصل 9):

1. ضع المؤشر بعد جدول المحتويات.
2. **Références** ثم **Insérer une table des illustrations**.
3. اختر **Étiquette de légende: Figure** (أو **Tableau** لقائمة الجداول) ثم **OK**.

```shot
id: W35
title: نافذة Légende
take: زر أيمن على صورة ثم Insérer une légende، وصوّر النافذة
legend:
- نص التعليق
- Étiquette: Figure / Tableau / Équation
- Position: Au-dessous de la sélection
- Nouvelle étiquette… (لكتابة «شكل» بالعربية)
```

> 💡 **نصيحة:** في مذكرة بالعربية: **Nouvelle étiquette** ثم اكتب «الشكل»، فيصبح التعليق «الشكل 1».

## 11-4 المراجع والبيبليوغرافيا

1. **Références** ثم **Style**: اختر **APA** (الأكثر طلباً في الجامعات) أو ما يطلبه أستاذك.
2. بعد الاقتباس: **Insérer une citation** ثم **Ajouter une nouvelle source**.
3. املأ النوع (كتاب، مقال، موقع)، المؤلف، العنوان، السنة، الناشر.
4. في آخر المذكرة: **Bibliographie** ثم اختر شكلاً: تُبنى القائمة تلقائياً ومرتبة.

```shot
id: W36
title: نافذة Créer une source
take: Références ثم Insérer une citation ثم Ajouter une nouvelle source، املأ مثالاً وهمياً وصوّر
legend:
- Type de source (Livre، Article…)
- Auteur
- Titre، Année، Éditeur
- Afficher tous les champs bibliographiques
```

```shot
id: W37
title: مجموعة Citations et bibliographie
take: صوّر النافذة مع تبويب Références مفتوحاً كاملاً
legend:
- Table des matières
- Notes de bas de page
- Citations et bibliographie: Style، Insérer une citation، Bibliographie
- Légendes
```

## 📝 الخلاصة

- عناوين بأنماط ← **Table des matières** تلقائية، حدّثها قبل الطباعة.
- **Ctrl+Alt+F** للحاشية.
- تعليقات الصور ← **Table des illustrations**.
- **Insérer une citation** + **Bibliographie** = قائمة مراجع مرتبة بلا عناء.
