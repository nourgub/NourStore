# الفصل 2: أنشئ واحفظ وافتح (**Fichiers**)

## 🎯 ماذا ستتعلم في هذا الفصل

- إنشاء مستند جديد فارغ أو من قالب.
- الحفظ لأول مرة والحفظ بعد التعديل.
- الفرق بين **Enregistrer** و**Enregistrer sous**.
- فتح مستند واستعادة ملف لم يُحفظ.

## 2-1 مستند جديد

- **فارغ:** **Fichier** ثم **Nouveau** ثم **Document vierge**، أو **Ctrl+N**.
- **من قالب** (**Modèle**): في نفس الصفحة اختر قالباً جاهزاً (سيرة ذاتية، رسالة، تقرير…) أو اكتب في خانة البحث «CV» أو «lettre».

```shot
id: W05
title: صفحة Nouveau والقوالب
take: Fichier ثم Nouveau، صوّر الصفحة كاملة (اختر قوالب بلا صور أشخاص إن أمكن)
legend:
- Document vierge (مستند فارغ)
- خانة البحث عن القوالب
- قوالب جاهزة
```

## 2-2 الحفظ لأول مرة

1. **Fichier** ثم **Enregistrer sous**، أو **F12**.
2. اختر المكان: **Ce PC** (الحاسوب) أو **OneDrive** (السحابة).
3. اكتب اسماً واضحاً: «CV-Amina-2026» أفضل من «Document1».
4. اترك النوع **Document Word (*.docx)** واضغط **Enregistrer**.

```shot
id: W06
title: نافذة Enregistrer sous
take: اضغط F12، اختر مجلداً، واكتب اسم الملف، ثم صوّر النافذة قبل الضغط على Enregistrer
legend:
- المجلد المختار
- خانة اسم الملف (Nom du fichier)
- نوع الملف (Type) : Document Word (*.docx)
- زر Enregistrer
```

## 2-3 الحفظ بعد كل تعديل

- **Ctrl+S** يحفظ التعديلات في نفس الملف.
- **Enregistrer sous** يصنع **نسخة جديدة** باسم أو مكان آخر، والملف الأصلي يبقى كما كان.
- إن كان الملف على OneDrive، يظهر مفتاح **Enregistrement automatique** (الحفظ التلقائي) أعلى اليسار.

> ⚠️ **تحذير:** عادة ذهبية: اضغط **Ctrl+S** كل بضع دقائق. انقطاع الكهرباء لا ينتظر.

| الصيغة | متى تستعملها |
|---|---|
| **.docx** | للعمل والتعديل (الصيغة العادية) |
| **.pdf** | للإرسال والطباعة: لا يتغير شكله على أي جهاز |
| **.dotx** | قالب تعيد استعماله |
| **.doc** | صيغة قديمة، فقط إن طلبها شخص يستعمل Word قديماً |

## 2-4 فتح مستند

- **Ctrl+O** أو **Fichier** ثم **Ouvrir**، ثم **Parcourir** (استعراض).
- أو انقر مرتين على الملف في المستكشف.
- قائمة **Récent** تعرض آخر الملفات.

## 2-5 استعادة مستند لم يُحفظ

أُغلق Word فجأة؟

1. أعد فتح Word: قد يظهر جزء **Récupération de document** بالنسخ المستعادة.
2. أو: **Fichier** ثم **Informations** ثم **Gérer le document** ثم **Récupérer les documents non enregistrés**.

```shot
id: W07
title: استعادة المستندات غير المحفوظة
take: Fichier ثم Informations، افتح قائمة Gérer le document، وصوّر الصفحة والقائمة مفتوحة
legend:
- صفحة Informations
- زر Gérer le document
- Récupérer les documents non enregistrés
```

## 📝 الخلاصة

- **Ctrl+N** جديد، **Ctrl+O** فتح، **Ctrl+S** حفظ، **F12** حفظ باسم.
- **.docx** للعمل، **.pdf** للإرسال.
- الاسم الواضح للملف يوفّر عليك البحث لاحقاً.

## 🛠️ تمرين

أنشئ مجلداً «دورة Word» في حاسوبك، واحفظ فيه ملفاً باسم «تمارين»، ثم أغلقه وافتحه من **Récent**.
