# الجزء الأول: البداية

# الفصل 1: اكتشف واجهة Word (**Interface**)

## 🎯 ماذا ستتعلم في هذا الفصل

- تشغيل Word وفتح مستند فارغ.
- أجزاء النافذة: الشريط، التبويبات، المجموعات.
- شريط الوصول السريع وشريط الحالة والتكبير.
- طرق العرض المختلفة.

## 1-1 تشغيل Word

1. اضغط زر **Windows** في لوحة المفاتيح، واكتب **Word**.
2. اضغط على **Word** في النتائج.
3. تظهر **صفحة البداية** (**Accueil**): اضغط **Nouveau document vierge** (مستند فارغ جديد).

```shot
id: W01
title: صفحة البداية في Word
take: شغّل Word وصوّر صفحة البداية قبل فتح أي مستند (النافذة كاملة)
legend:
- القائمة الجانبية: Accueil، Nouveau، Ouvrir
- مستند فارغ جديد (Nouveau document vierge)
- القوالب الجاهزة (Modèles)
- آخر المستندات التي فتحتها (Récent)
```

## 1-2 أجزاء النافذة

بعد فتح مستند فارغ، تتكوّن النافذة من أجزاء ثابتة ستستعملها كل يوم:

```shot
id: W02
title: نافذة Word بعد فتح مستند فارغ
take: افتح مستنداً فارغاً واكتب سطراً واحداً، ثم صوّر النافذة كاملة
legend:
- شريط العنوان: اسم الملف، وخانة البحث (Rechercher)
- التبويبات: Fichier، Accueil، Insertion، Mise en page…
- الشريط (Ruban) بمجموعاته: Presse-papiers، Police، Paragraphe، Styles
- مساحة الكتابة (الصفحة البيضاء)
- شريط الحالة: رقم الصفحة، عدد الكلمات، اللغة
- طرق العرض والتكبير (Zoom)
```

| الجزء | الاسم بالفرنسية | وظيفته |
|---|---|---|
| التبويبات | **Onglets** | تجمع الأوامر حسب الموضوع |
| الشريط | **Ruban** | الأزرار الخاصة بالتبويب المفتوح |
| المجموعة | **Groupe** | قسم داخل الشريط، مثل **Police** |
| شريط الوصول السريع | **Barre d'outils Accès rapide** | أزرار تحبها دائماً في متناولك |
| شريط الحالة | **Barre d'état** | معلومات المستند والتكبير |

## 1-3 التبويبات الرئيسية

| التبويب | ماذا تجد فيه |
|---|---|
| **Fichier** | الحفظ، الفتح، الطباعة، التصدير PDF |
| **Accueil** | الخط، الفقرة، الأنماط، البحث |
| **Insertion** | الجداول، الصور، الأشكال، الرأس والتذييل، أرقام الصفحات |
| **Dessin** | الكتابة باليد والقلم |
| **Création** | سمات المستند، العلامة المائية، حدود الصفحة |
| **Mise en page** | الهوامش، الاتجاه، الحجم، الأعمدة، الفواصل |
| **Références** | جدول المحتويات، الحواشي، المراجع |
| **Publipostage** | دمج المراسلات (رسائل لعدة أشخاص) |
| **Révision** | التدقيق، التعليقات، تتبع التغييرات |
| **Affichage** | طرق العرض، المسطرة، جزء التنقل |

> 💡 **نصيحة:** في أسفل يمين بعض المجموعات سهم صغير ↘ اسمه **Lanceur de boîte de dialogue**. يفتح نافذة فيها كل خيارات المجموعة.

```shot
id: W03
title: السهم الصغير لفتح نافذة الخيارات
take: في تبويب Accueil، اضغط السهم الصغير أسفل مجموعة Police، وصوّر النافذة التي تظهر مع الشريط خلفها
legend:
- السهم الصغير في زاوية مجموعة Police
- نافذة Police بكل خيارات الخط
```

## 1-4 شريط الوصول السريع

أضف إليه الأوامر التي تستعملها كثيراً، مثل **Enregistrer** و**Annuler**:

1. اضغط السهم الصغير بجانب شريط الوصول السريع (أعلى النافذة).
2. ضع علامة على الأوامر التي تريدها.

> 📌 **ملاحظة:** في بعض نسخ Microsoft 365 يكون الشريط مخفياً. اضغط بالزر الأيمن على الشريط ثم **Afficher la barre d'outils Accès rapide**.

## 1-5 طرق العرض والتكبير

- **Mode Page** (عرض الصفحة): الطريقة العادية، ترى الصفحة كما ستُطبع.
- **Mode Lecture** (القراءة): لقراءة مريحة بلا أزرار.
- **Web** (ويب): لنص بلا فواصل صفحات.
- **Zoom**: اسحب المؤشر في شريط الحالة، أو اضغط **Ctrl** مع عجلة الفأرة.

```shot
id: W04
title: تبويب Affichage
take: افتح تبويب Affichage وصوّر النافذة كاملة
legend:
- طرق العرض: Mode Lecture، Page، Web
- خانة Règle (المسطرة) وVolet de navigation (جزء التنقل)
- أزرار التكبير (Zoom)
```

## 📝 الخلاصة

- النافذة = تبويبات، وتحت كل تبويب شريط مقسّم إلى مجموعات.
- **Accueil** للكتابة اليومية، **Insertion** لإضافة العناصر، **Mise en page** للصفحة.
- خانة **Rechercher** في الأعلى تجد أي أمر بالاسم.

## 🛠️ تمرين

افتح مستنداً فارغاً، وتجوّل في كل التبويبات العشرة، واكتب في ورقة اسم أمرين لفتا انتباهك في كل تبويب.
