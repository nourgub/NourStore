# الفصل 12: المشاركة والتصدير والطباعة

## 🎯 الأهداف

- تصدير العرض PDF أو فيديو.
- طباعة الملاحظات والنُّسخ الموزّعة.
- فحص إمكانية الوصول وتصغير حجم الملف قبل الإرسال.

## 12-1 التصدير

**Fichier** ثم **Exporter**:

```shot
id: P22
title: شاشة Exporter
legend:
- Créer un document PDF/XPS
- Créer une vidéo (الجودة واستعمال التسجيلات)
- Créer des documents (نسخة Word للملاحظات)
- Modifier le type de fichier (قالب .potx، صور…)
```

- **PDF:** للإرسال بالبريد أو للطباعة: يظهر بنفس الشكل على كل جهاز.
- **فيديو (.mp4):** للنشر على الإنترنت أو للعرض بلا PowerPoint. اختر الجودة، و**Utiliser les minutages et narrations enregistrés** إن سجّلت صوتك.

## 12-2 الطباعة

**Fichier** ثم **Imprimer**، ثم القائمة **Diapositives en pleine page**:

```shot
id: P23
title: خيارات الطباعة
legend:
- Diapositives en pleine page / Pages de commentaires / Plan
- Documents: 3 diapositives par page (مع أسطر للكتابة)
- Couleur / Nuances de gris
- المعاينة
```

## 12-3 قبل الإرسال

- **Révision** ثم **Vérifier l'accessibilité**: يكشف الصور بلا نص بديل، والنص الضعيف التباين، والشرائح بلا عنوان.
- **Fichier** ثم **Informations** ثم **Vérifier la présence de problèmes** ثم **Inspecter le document**: يحذف الملاحظات والتعليقات المخفية إن أردت.
- **Compresser les images** و**Compresser le média** لتصغير الملف.

```shot
id: P24
title: جزء Accessibilité
legend:
- زر Vérifier l'accessibilité
- الأخطاء: Texte de remplacement manquant، Titre de diapositive manquant…
- اقتراحات الإصلاح لكل خطأ
```

## 💼 مثال تطبيقي

بعد اجتماع، يرسل المدير العرض للمشاركين: يصدّره PDF، ويطبع **Documents: 3 diapositives par page** لمن يريد الكتابة، ويحذف الملاحظات الداخلية بـ **Inspecter le document** قبل إرسال ملف PowerPoint نفسه.

## ⚠️ أخطاء شائعة

- **إرسال ملف PowerPoint بملاحظات خاصة:** الملاحظات تصل مع الملف. أرسل PDF أو احذفها.
- **ملف كبير يرفضه البريد:** اضغط الصور والوسائط، أو أرسل رابط OneDrive.
- **خطوط غير موجودة على حاسوب آخر:** **Fichier** ثم **Options** ثم **Enregistrement** ثم **Incorporer les polices dans le fichier**.
- **طباعة شرائح بخلفية داكنة:** تستهلك الحبر. اختر **Nuances de gris**.

## 🛠️ تمرين

صدّر **Projet3-Bilan-des-ventes.pptx** إلى PDF، ثم شغّل **Vérifier l'accessibilité** وأصلح ما يقترحه.

**✅ تحقّق:** ملف PDF من 5 صفحات بنفس شكل الشرائح، وجزء **Accessibilité** لا يعرض أخطاء (**Aucun problème d'accessibilité**) أو يعرض تحذيرات فقط.

## ❓ اختبار قصير

1. أي صيغة تحافظ على الشكل على كل جهاز؟ (أ) PDF (ب) .pptx (ج) .txt
2. أي خيار طباعة يترك أسطراً للكتابة بجانب الشرائح؟ (أ) Plan (ب) Documents: 3 diapositives par page (ج) Pleine page
3. أين تجد Vérifier l'accessibilité؟ (أ) Révision (ب) Insertion (ج) Animations

## 📝 الخلاصة

- **Exporter** ثم PDF أو فيديو.
- **Documents: 3 diapositives par page** للجمهور، و**Pages de commentaires** لك.
- افحص إمكانية الوصول واضغط الملف قبل الإرسال.
