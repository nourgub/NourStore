# الفصل 11: تقديم العرض (**Diaporama**)

## 🎯 الأهداف

- بدء العرض والتنقل فيه بلوحة المفاتيح.
- استعمال **Mode Présentateur** مع الملاحظات والمؤقّت.
- التدرّب بالتوقيت وتسجيل العرض.

## 11-1 بدء العرض والتنقل

```shot
id: P20
title: تبويب Diaporama
legend:
- À partir du début (F5) / À partir de la diapositive actuelle (Maj+F5)
- Diaporama personnalisé
- Configurer le diaporama
- Vérifier le minutage وEnregistrer
- Utiliser le mode Présentateur
```

| أثناء العرض | اضغط |
|---|---|
| الشريحة التالية | **Entrée** أو **Espace** أو **→** |
| الشريحة السابقة | **Retour arrière** أو **←** |
| الذهاب إلى شريحة رقمها 5 | **5** ثم **Entrée** |
| شاشة سوداء / بيضاء | **.** (نقطة) / **,** (فاصلة) |
| إنهاء العرض | **Échap** |

## 11-2 Mode Présentateur

مع شاشتين (الحاسوب والعارض)، يرى الجمهور الشريحة فقط، وترى أنت:

```shot
id: P21
title: Mode Présentateur
legend:
- المؤقّت وزر الإيقاف المؤقت
- الشريحة الحالية كما يراها الجمهور
- الشريحة التالية
- ملاحظاتك بخط كبير (A+ / A−)
- أدوات: القلم، التكبير، عرض كل الشرائح
```

لتجربته بشاشة واحدة: في العرض، زر أيمن ثم **Afficher le mode Présentateur** (أو **Alt+F5** لبدء العرض به).

## 11-3 التدرّب والتسجيل

- **Vérifier le minutage:** يعرض الشرائح ويحسب الوقت الذي تقضيه في كل شريحة.
- **Enregistrer** (تبويب **Enregistrement** أو **Diaporama**): يسجّل صوتك وكاميرتك مع الشرائح، لعرض بلا مقدّم أو لتصديره فيديو (الفصل 12).
- **Configurer le diaporama** ثم **Visionné sur une borne (plein écran)**: عرض يدور وحده في معرض أو مدخل.

## 💼 مثال تطبيقي

طالب يتدرّب على مناقشة مذكرته في 15 دقيقة: يستعمل **Vérifier le minutage**، فيكتشف أنه يقضي 4 دقائق في شريحة المنهجية، فيختصر كلامه. يوم المناقشة يستعمل **Mode Présentateur** ليرى ملاحظاته والمؤقّت.

## ⚠️ أخطاء شائعة

- **قراءة الشرائح بصوت عالٍ:** الجمهور يقرأ أسرع منك. اشرح، ولا تقرأ.
- **الظهر للجمهور:** انظر إلى شاشة الحاسوب في **Mode Présentateur** لا إلى الشاشة الكبيرة.
- **عدم التجربة على حاسوب القاعة:** الخطوط والفيديو والدقة قد تختلف. جرّب قبل يوم.
- **الشريحة الأولى مكشوفة قبل البدء:** اضغط مفتاح النقطة **.** لشاشة سوداء أثناء الانتظار (المفتاح بالحرف يختلف حسب لغة النسخة).

## 🛠️ تمرين

افتح **Projet4-Soutenance-memoire.pptx** واكتب ملاحظة في كل شريحة، ثم اعرضه بـ **Alt+F5** وتنقّل بالمفاتيح: اذهب إلى الشريحة 6 بكتابة 6 ثم **Entrée**، ثم شاشة سوداء بمفتاح النقطة **.**.

**✅ تحقّق:** في **Mode Présentateur** ترى ملاحظاتك والشريحة التالية والمؤقّت، والجمهور (الشاشة الثانية أو معاينة الشريحة) لا يرى الملاحظات.

## ❓ اختبار قصير

1. أي اختصار يبدأ العرض من الشريحة الحالية؟ (أ) F5 (ب) Maj+F5 (ج) Ctrl+F5
2. ماذا يرى الجمهور في Mode Présentateur؟ (أ) الشريحة فقط (ب) الشريحة والملاحظات (ج) كل الشرائح
3. أي أداة تحسب الوقت لكل شريحة؟ (أ) Vérifier le minutage (ب) Morphose (ج) Designer

## 📝 الخلاصة

- **F5** من البداية، و**Maj+F5** من الشريحة الحالية، و**Échap** للإنهاء.
- **Mode Présentateur**: ملاحظاتك ومؤقّتك أمامك وحدك.
- تدرّب بالتوقيت، وجرّب على حاسوب القاعة.
