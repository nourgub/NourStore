# مساعد المبيعات الذكي للمتاجر الإلكترونية الجزائرية

مساعد محادثة يجيب الزبائن بالعربية والدارجة والفرنسية والإنجليزية، يبحث عن الأسعار والمخزون الحقيقي، يحسب التوصيل حسب الولاية، يُحضّر الطلبات ويتابعها. مبني على Claude (`claude-haiku-5-5`) مع استدعاء الأدوات، وFlask وSQLite.

> English documentation: [README.md](README.md)

## كيف يعمل

1. الزبون يكتب سؤاله في واجهة المحادثة.
2. المساعد يستدعي أدوات المتجر: البحث عن المنتجات (السعر والمخزون من قاعدة البيانات)، متابعة طلب (برقم الطلب **و**رقم الهاتف معًا)، وتحضير ملخص طلب.
3. يظهر للزبون ملخص الطلب مع زر **«تأكيد الطلب»**.
4. عند الضغط على الزر فقط، يتحقق الخادم من المخزون ويسجّل الطلب في لوحة الإدارة.

## الأمان

- **الذكاء الاصطناعي لا يستطيع إنشاء طلب بنفسه**؛ يستطيع فقط تحضير ملخص. الطلب يُسجَّل بضغطة الزبون على زر التأكيد.
- **الأسعار والمخزون من قاعدة البيانات دائمًا**، والتقييم يختبر ذلك حتى أمام رسائل تحاول تغيير الأسعار.
- **لا بيع لنفس القطعة مرتين**: حجز المخزون يتم في معاملة واحدة. اختُبر مع 6 مشترين في نفس اللحظة لآخر حاسوب: طلب واحد ينجح والباقون يتلقون رسالة واضحة.
- **لوحة الإدارة مغلقة افتراضيًا** حتى تضع `ADMIN_TOKEN` قويًا (16 حرفًا على الأقل) في `.env`. الرمز يُرسل في ترويسة الطلب فقط.
- **نصوص الزبائن تُعرض كنص عادي** في كل الصفحات، فلا يمكن حقن كود عبر اسم أو رسالة.
- **حدّ لعدد الرسائل** لكل زبون لحماية رصيد API الخاص بالمتجر.

## التشغيل

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env      # ضع ANTHROPIC_API_KEY و ADMIN_TOKEN طويلًا وعشوائيًا
python app.py             # http://127.0.0.1:5000  و  /admin
```

للنشر: ملف `Dockerfile` جاهز، وخطوات نشر نسخة تجريبية آمنة (حدّ للإنفاق وحدّ يومي) في [DEPLOY.md](DEPLOY.md).

## الاختبارات والتقييم

- **35 اختبارًا** دون إنترنت ودون مفتاح API: `pytest -q`.
- **تقييم سلوكي من 24 محادثة** بالعربية والدارجة والفرنسية والإنجليزية: `python -m evals.run_eval` (يحتاج مفتاح API، وتكلفته بضعة سنتات).

## التخصيص لكل متجر

عدّل `STORE_NAME` و`DB_PATH` و`ADMIN_TOKEN` و`ANTHROPIC_API_KEY` في `.env`، أدخل المنتجات الحقيقية في جدول `products`، ثم ضع `SEED_DEMO_DATA=false`. قواعد التوصيل في أعلى ملف `db.py`.

## الحدود الحالية

- رمز إدارة واحد بدل حسابات متعددة للموظفين.
- حدّ الرسائل داخل الخادم نفسه؛ مع عدة خوادم يُنقل إلى Redis أو إلى Nginx.
- SQLite مناسب لمتجر صغير؛ مع حجم طلبات كبير يُنقل إلى PostgreSQL.
- لا يوجد ربط بواتساب أو ماسنجر بعد؛ المحادثة على موقع المتجر.
- الدفع عند الاستلام فقط.
