# مساعد المبيعات الذكي للمتاجر الإلكترونية الجزائرية

مساعد محادثة يجيب الزبائن بالعربية والدارجة والفرنسية والإنجليزية، يبحث عن الأسعار والمخزون الحقيقي، يحسب التوصيل حسب الولاية، يحضّر الطلبات ويتابعها، مع لوحة إدارة للطلبات والمنتجات والحسابات. مبني على Claude (`claude-haiku-5-5`) مع استدعاء الأدوات، وFlask وSQLite.

> English documentation: [README.md](README.md) · النشر: [DEPLOY.md](DEPLOY.md)

## كيف يُسجَّل الطلب

1. الزبون يكتب سؤاله.
2. المساعد يستدعي أدوات المتجر: البحث عن المنتجات، متابعة طلب (برقم الطلب **و**الهاتف معًا، دون إرجاع بيانات شخصية)، وتحضير ملخص طلب.
3. الخادم يتحقق من كل شيء ويحسب الأسعار ورسوم التوصيل حسب الولاية من قاعدة البيانات.
4. يظهر ملخص الطلب مع زر «تأكيد الطلب»، ثم سؤال «هل أنت متأكد؟».
5. عند التأكيد فقط، يُعاد التحقق من المخزون في معاملة واحدة ويُسجَّل الطلب.

**الذكاء الاصطناعي لا يملك أي أداة لإنشاء أو تأكيد الطلبات**، وأي أسعار أو مجاميع أو رسوم يرسلها النموذج أو المتصفح تُتجاهل.

## الأمان وحماية البيانات

- **حسابات منفصلة للموظفين** بكلمات مرور مشفّرة (hash)، وجلسات قصيرة مخزّنة في الخادم، وخروج يُلغي الجلسة فورًا، ورمز CSRF لكل تعديل، وحدّ لمحاولات الدخول لكل IP ولكل حساب.
- **الأدوار:** `admin` يدير المستخدمين والمنتجات والمخزون والطلبات، و`staff` يرى الطلبات ويغيّر حالتها فقط. التحقق في الخادم.
- **رمز `ADMIN_TOKEN` القديم** يعمل فقط مع `DEMO_MODE=true`، وغير مناسب للإنتاج.
- **ترويسات أمان** (CSP دون سكربتات داخلية، منع التضمين في إطارات، إلخ)، وCORS مغلق إلا للنطاقات المحددة.
- **حدود للاستعمال** منفصلة للمحادثة والتأكيد ومتابعة الطلب والدخول والإدارة، مشتركة عبر Redis عند ضبط `REDIS_URL`.
- **السجلات (logs)** بصيغة JSON مع رقم لكل طلب، وأرقام الهواتف مخفية (`05******56`)، ودون مفاتيح API أو كلمات مرور أو نصوص المحادثات.

## البيانات الشخصية

| البيان | لماذا | مدة الاحتفاظ |
|---|---|---|
| رسائل المحادثة | تُرسل إلى Anthropic لتوليد الرد | لا يحفظها التطبيق |
| الاسم والهاتف والولاية | تحضير الطلب وتوصيله | الملخص غير المؤكد: 24 ساعة. الطلب المسلَّم أو الملغى: يُحذف الاسم والهاتف بعد 365 يومًا عبر `flask --app app purge-data` |
| عنوان IP | الحماية من الاستعمال المفرط | عدّادات مؤقتة فقط |

صفحة الخصوصية للزبائن: `/privacy`.

## التشغيل

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env      # ضع ANTHROPIC_API_KEY، و SESSION_COOKIE_SECURE=false للتجربة على http محليًا
flask --app app migrate
flask --app app create-user --username you --role admin   # يطلب كلمة مرور من 12 حرفًا على الأقل
python app.py             # http://127.0.0.1:5000  ولوحة الإدارة على /admin
```

## أوامر الإدارة

| الأمر | الغرض |
|---|---|
| `flask --app app migrate` | تحديث قاعدة البيانات (آمن على القواعد القديمة) |
| `flask --app app create-user --username NAME --role admin` | إنشاء حساب |
| `flask --app app purge-data` | تطبيق سياسة الاحتفاظ (يوميًا) |
| `python scripts/backup.py --keep 14` | نسخة احتياطية أثناء التشغيل |
| `python scripts/restore.py backups/store-….db` | الاسترجاع (أوقف التطبيق أولًا) |

## الاختبارات والتقييم

- **212 اختبارًا** دون إنترنت ودون مفتاح API: `python -m pytest -q`.
- **تقييم سلوكي من 24 محادثة** (عدد الحالات في `evals/cases.json`) بالعربية والدارجة والفرنسية والإنجليزية: `python -m evals.run_eval`. يحتاج مفتاح API، وتكلفته بضعة سنتات، ويطبع تكلفة المحادثة الفعلية.

## التجربة مقابل الإنتاج

| | تجربة (Demo) | إنتاج |
|---|---|---|
| دخول الإدارة | `DEMO_MODE=true` مع `ADMIN_TOKEN` قوي | حسابات الموظفين فقط |
| الكوكيز | `SESSION_COOKIE_SECURE=false` محليًا | `true` مع HTTPS و`ENABLE_HSTS=true` |
| الميزانية | `DAILY_CHAT_LIMIT` + حدّ إنفاق في Anthropic | حدّ إنفاق ومراقبة `/metrics` |
| العمّال (workers) | 1 | 1، أو أكثر مع `REDIS_URL` |

## الحدود الحالية

- SQLite مناسب لخادم واحد. كل استعلامات SQL محصورة في `db.py` و`migrations.py` لتسهيل الانتقال إلى PostgreSQL، لكن الانتقال نفسه لم يُنفَّذ.
- رسوم التوصيل المبدئية لكل ولاية قيم تجريبية (600 للعاصمة، 1200 للجنوب الكبير، 900 لغيرها)؛ ضع أسعار شركة التوصيل الحقيقية في جدول `wilayas`.
- المحادثة على موقع المتجر فقط (لا واتساب بعد)، والدفع عند الاستلام فقط.
